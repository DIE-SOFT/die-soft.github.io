# DIE SOFT Webpage

### Setup

See [GitHub's documentation](https://docs.github.com/en/pages/setting-up-a-github-pages-site-with-jekyll/testing-your-github-pages-site-locally-with-jekyll). Use Ruby 3.3 w/ Devkit from [here](https://rubyinstaller.org/downloads/) if installing Ruby. Make sure to run `bundle install` in the directory and then you should be ready.

### Running

Simply run the `jekyll.sh` script to launch the local server.
